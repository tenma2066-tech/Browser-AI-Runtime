## iOS 実機（初回・較正前）

- 馴染み(雨)学習 → 動物注入で **Meta制御が全パス固定lrより速い**:
  pass1 固定2.661/Meta2.464 … pass5 固定1.262/Meta1.223。
- 質問フラグ 3回発火（「猫が窓辺」「犬と猫は」等の新規混乱に）。
- 自己テスト core=PASS / meta=PASS。

### 判明した弱点と修正: 基準の較正

適応lrで馴染み学習すると、`emaSurprise`（基準）が学習初期の高 surprise を平均して
膨らみ（実機で 2.07）、新規との差（lrFactor）が縮んでいた。

→ **学習して到達した水準を基準に較正**する処理を追加（その領域に習熟したことの
認識。長い定常ストリームで EMA が収束するのと同じ効果を短時間で得る）。

較正後（Node）: 基準 1.304、新規 lrFactor 序盤 **1.83**（較正前 1.29 から改善）、
Meta制御と固定lrの差が明確に（pass1 固定2.661/Meta2.364 … pass5 固定1.262/Meta1.146）、
質問 6回。

## 意味

- **AI が自分の学び方を自分で制御**するようになった:
  - 馴染んだ入力では学習率を抑え（過学習・破滅的忘却の抑制＝凍結寄り）、
  - 新規に驚くと学習率を上げて速く適応し、
  - 混乱が持続したときだけ問い返す（能動学習）。
- すべて **surprise（予測誤差）という単一の内部信号**から出ている。Phase 2a で
  「学習・自己評価・記憶の取捨」を担った信号が、Phase 3 で「学習率・質問」まで
  制御する。ビジョンの「思考する・自己評価する・質問する・学習する」が繋がった。
