## 判定

| 受け入れ条件 | 結果 | 実測（実機） |
|---|---|---|
| #1 概念化 | ✅ | 3話題（天気/食事/移動）→ 3概念クリーン（各3件統合） |
| #2 一般化想起 | ✅ | 「ご飯を食べたい」→ ★食事概念がトップ（score 0.71） |
| #3 忘却と両立 | ✅ | 強 decay 後 エピソード生存 0/9・概念生存 3/3、再想起で概念のみ |

| #5 同居 | ✅ | 概念は別構造でなく属性（provenance='concept', count）で区別 |

## 意味

- **忘却と一般化が両立**: 個別の経験（エピソード）は薄れて消えるのに、そこから
  抽出した概念は低可塑で残り続ける。「昨日何を食べたか」は忘れても「食事という
  概念」は保つ、という人間的な記憶の性質を実装で再現した。
- 概念も同じ Memory Fabric に同居（ADR-0001「同一ベクトル空間・属性で区別」）。

## 実装知見

- 静的 substrate の文ベクトルは異方性で圧縮される（全ペアが高 cos）。**平均除去
  してからクラスタリング**することでトピックが綺麗に分離する（クラスタ用の類似度
  にのみ適用し、概念 centroid は元ベクトルから作って想起空間を保つ）。
- クラスタ純度は substrate の埋め込み品質に依存。語彙が反復する話題（実データも
  そうなる）では綺麗に分離するが、抽象度が高く語彙が重ならない話題は Phase 2b/2b-2
  と同じ天井がある。leader clustering は単純で、厳密な linkage は将来。

## 到達点（Phase 0〜3b）

```
Runtime → Representation(自作/静的substrate/自前Transformer)
        → Memory Fabric(記銘/想起/強化/忘却/★概念化)
        → Cognitive Core(char/subword・予測・双方向ループ)
        → Meta Cognition(適応学習率・質問)
```

思考・自己評価・質問・学習・忘却・概念化——ビジョンの認知要素が一通り実機で動作。
